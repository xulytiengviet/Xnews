KẾT NỐI NGUỒN DỮ LIỆU

Đưa trạm tin vào hoạt động

  1. Tạo ứng dụng trên X Developer; kiểm tra quyền đọc và ngân sách API.
  2. Trong GitHub → Settings → Secrets and variables → Actions, thêm secret X_BEARER_TOKEN.
  3. Trong Settings → Pages, chọn nguồn GitHub Actions.
  4. Mở Actions → Xnews monitor and Pages → Run workflow.

Token chỉ được dùng trong GitHub Actions. Không nhập token vào dashboard. Chỉnh danh sách tại accounts.json.

Lịch 30 phút có thể bị GitHub trì hoãn. Làm mới trang chỉ đọc dữ liệu đã thu thập, không gọi trực tiếp X API.
